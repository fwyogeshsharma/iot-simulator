# PowerPoint Generator Tools

Scripts for generating PowerPoint presentations about the IoT Simulator project.

## Setup

```bash
cd tools/ppt-generator
npm install
```

## Available Scripts

### create-ppt.js
Generates a presentation about SymbIOT sensors and devices.

```bash
node create-ppt.js
```

### create-architecture-ppt.js
Generates a presentation about the system architecture.

```bash
node create-architecture-ppt.js
```

## Dependencies

- `pptxgenjs` - PowerPoint file generation library
